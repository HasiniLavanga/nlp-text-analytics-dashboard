# NLP Text Analytics Dashboard

## Project Overview

This project performs end-to-end Natural Language Processing (NLP) on customer review data.

Features include:

- Text Preprocessing
- Topic Modeling using LDA
- Sentiment Analysis using VADER
- Named Entity Recognition using spaCy
- Interactive Streamlit Dashboard
- Keyword-Based Review Search

## Technologies Used

- Python
- Pandas
- spaCy
- Scikit-learn
- Plotly
- Streamlit
- VADER Sentiment Analyzer

## Dashboard Features

- Review Analytics
- Sentiment Distribution
- Topic Extraction
- Entity Recognition
- Search Functionality

## Dataset

Women's E-Commerce Clothing Reviews Dataset

## Project Outcome

The dashboard enables users to analyze customer reviews, identify major discussion topics, evaluate sentiment trends, and extract meaningful entities from text data.
